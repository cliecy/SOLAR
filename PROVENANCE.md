# Scientific provenance

This release starts from upstream `main` commit
`a0b8c6a390b5ed3443b255fb6ff695557c62241b` and integrates the completed
450-fit campaign used by the revised SOLAR manuscript and supplement.
The historical publication package and all original private experiment records
are preserved. Packaging performs score aggregation and figure reconstruction;
no training or fresh embedding-level scoring was run.

## Evidence lineage

| Evidence | Origin and retained record |
|---|---|
| Historical cross-method, dimension and anchor comparisons | Upstream `data/heldout/` and frozen tables; PCA, scVI, scANVI and SCLSC remain included |
| Historical within-batch widths and batch composition | Upstream `data/within_batch/` and `data/splits/` |
| Latest 450 fitted models | Final campaign `COMPLETE.json` and its nine checksum-bound CSVs, projected into `data/campaign450/` |
| Reference-validation arm selection | All 450 saved validation candidate records and all 45 matched 30D selection groups; the sole removed candidate field is the machine-specific `run` path |
| Campaign uncertainty | Original exact dataset-stratified paired bootstrap, extracted into `scripts/replay_campaign.py` with unchanged numerical computation |
| Historical paired uncertainty | Final manuscript evidence: two CSVs, regenerated by `scripts/replay_historical_uncertainty.py` |
| Hierarchy/local scientific extensions | Original campaign `install_extension` computation, extracted to `src/SOLAR/benchmark/reviewer_extensions.py` with output/log arguments made explicit |

The campaign's original hashes are retained in `data/campaign450/COMPLETE.json`
as `source_derived_sha256`; the portable CSV hashes are `derived_sha256`.
Other campaign CSVs are byte-identical to their original frozen sources.
Historical configs are scientific projections of upstream configs: inactive
model/launch sections and machine-specific fields are omitted. Exact source
excerpts needed for historical static claims are in
`configs/historical_source_contracts.json`. The complete upstream execution
sources remain available in the recorded base commit's Git history.

The historical official scIB backend was commit
`e2a37e0ed63dc34b60aa535cc656400552af757a`, with kBET commit
`afc5f431bcbefd73267acc066a0f2e4eaa10a355`. Score replay retains their recorded
values and applicability rather than attempting to reconstruct this legacy runtime.
The historical SCLSC source revision is recorded in the reproduction guide;
its upstream implementation is not redistributed.

## Historical numerical corrections

The historical training implementation could compute `log(0)` for a view without
a positive, and could step the optimizer on an all-distinct no-anchor mini-batch.
The current model source avoids both cases. The original audit found that these
cases did not occur in the historical held-out runs, so those fits were retained.
Historical scANVI metadata incorrectly marked query labels visible; the fitting
pipeline had replaced those labels with `Unknown` before frozen encoding.
The original audit and worker records remain in the historical release attachments.

The within-batch width table derives from the historical raw metrics file with
SHA-256 `d0e65f5b2a03f77525a54e82281e5ac69c05596a865cb518acfde07ccdeba97a`.
Historical execution names containing `v1_1` or `v1_2` are experiment identifiers;
they do not identify a new published software version.

## Interpretation and rights

Reference-validation selection was introduced after initial query-score exposure;
it does not create an unseen confirmatory benchmark. All candidates and all
endpoints remain available, including negative comparisons. Bootstrap intervals
are descriptive and conditional on these datasets, with seeds averaged before
batch resampling. See [the verification contract](docs/reproduction.md).

The original MIT license and citation author metadata are preserved. Score records
are author-generated; processed source datasets are attributed to the scIB
Figshare collection under CC BY 4.0. No raw expression matrix, external model
source, private review correspondence or machine configuration is added.
